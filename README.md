# 여행 통역기 (한국어 ↔ English)

여행지에서 바로 쓸 수 있는 실시간 영어 대화 통역 웹앱(PWA)입니다. 설치 없이 브라우저에서 열고, 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

## 기능
- **실시간 음성 통역**: 🎤를 누르고 말하면 말하는 도중에 번역이 표시되고, 말을 멈추면 최종 번역을 음성으로 읽어 줍니다.
- **마주보기 모드**: 휴대폰을 테이블에 놓으면 위쪽(영어) 화면이 상대방 쪽으로 뒤집혀 보입니다. 상대방은 자기 쪽 🎤를 눌러 영어로 말하면 됩니다.
- **여행 회화 📖**: 공항·호텔, 교통, 식당, 쇼핑, 긴급 상황 필수 문장 (미리 번역돼 있어 **오프라인에서도 사용 가능**).
- **텍스트 입력 ⌨️**: 시끄러운 곳에서는 직접 입력해서 번역.
- **대화 기록 🕘**: 기기에만 저장, 🔊로 다시 듣기.
- **설정 ⚙️**: 영어 발음(미국/영국/호주/인도), 읽기 속도, 자동 읽기, 실시간 번역, 화면 켜짐 유지.

## 실행
마이크는 **HTTPS** 에서만 동작합니다.

- **GitHub Pages**: `main` 에 push 하면 `.github/workflows/pages.yml` 이 자동 배포합니다 → https://ksangki.github.io/translator/
  (최초 1회: 저장소 Settings → Pages → Source 를 **GitHub Actions** 로 설정)
- **로컬 테스트**: `python3 -m http.server 8000` 후 `http://localhost:8000` (localhost는 HTTPS 없이도 마이크 허용)

휴대폰에서 연 뒤 공유 메뉴 → **홈 화면에 추가** 하면 앱처럼 실행됩니다.

## 참고
- 음성 인식(브라우저 내장)과 번역은 인터넷 연결이 필요합니다. 오프라인에서는 여행 회화만 사용할 수 있어요 — 현지 유심/eSIM 또는 로밍을 준비하세요.
- 번역은 Google 번역 공개 엔드포인트를 쓰고, 실패하면 MyMemory 번역 API로 자동 전환합니다. 둘 다 무료·비공식 용도라 사용량 제한이 있을 수 있습니다.
- 입력한 문장은 번역 서비스로 전송됩니다. 여권번호·카드번호 같은 민감한 정보는 말하거나 입력하지 마세요.
